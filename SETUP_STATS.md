# Profile setup (2 minutes)

The stats cards are generated by `.github/workflows/profile.yml` straight from GitHub's
contribution calendar, so the numbers match your profile exactly.

1. **Create a token** → https://github.com/settings/tokens/new (classic)
   - Scopes: `repo` and `read:user` · Expiration: No expiration (or 1 year)
2. **Add it as a secret** → this repo → Settings → Secrets and variables → Actions →
   New repository secret → Name: `METRICS_TOKEN`, value: the token.
3. **Allow private contributions on your profile** → https://github.com/settings/profile →
   Contributions & activity → tick **"Include private contributions on my profile"**.
4. **Run it** → Actions tab → "Update profile stats & snake" → Run workflow.
   It then refreshes automatically every 6 hours.

Without the secret the workflow still runs, but only public activity is counted.

Edit the header / project cards / buttons in `scripts/build-assets.mjs`, then run
`node scripts/build-assets.mjs` to regenerate `assets/`.
Preview stats locally with sample data: `node scripts/generate-stats.mjs dist --mock`.
