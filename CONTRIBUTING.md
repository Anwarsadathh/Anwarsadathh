# Contributing to Anwarsadathh's Projects

Thank you for visiting my profile! Here's how you can contribute to my projects.

## 🚀 Getting Started

1. **Fork the repository** - Click the fork button on the repo
2. **Clone your fork** - `git clone https://github.com/YOUR-USERNAME/repo-name.git`
3. **Create a branch** - `git checkout -b feature/your-feature-name`
4. **Make changes** - Code your improvements
5. **Commit** - `git commit -m "🎯 Description of changes"`
6. **Push** - `git push origin feature/your-feature-name`
7. **Pull Request** - Create a PR on GitHub

## 📋 Commit Message Format

```
[type] emoji - Description

Types:
- 🎨 refactor: Code restructuring
- ✨ feat: New feature
- 🐛 fix: Bug fix
- 📝 docs: Documentation
- 🧪 test: Tests
- ⚙️ config: Configuration
- 🔧 chore: Maintenance
```

## ✅ Code Standards

- Write clean, readable code
- Add comments for complex logic
- Follow existing code style
- Test before submitting PR

## 📞 Questions?

- Open an issue for questions
- Check existing issues first
- Be respectful and constructive
